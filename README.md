# Enterprise-LAN-with-VLANs-STP-and-Inter-VLAN-Routing
This repository contains a Cisco Packet Tracer project simulating a small-to-medium business (SMB) enterprise network. The design follows a hierarchical Core/Distribution/Access model with VLAN segmentation, inter-VLAN routing, DHCP/DNS services, NAT at the edge, and guest Wi-Fi isolation.
